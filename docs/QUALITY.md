# Quality scorecard

A harsh self-review, 0–10 per area, with the evidence behind each score and what would raise it. A score only goes up when the
evidence is a command or test anyone can re-run. "Blocked" means the next step needs API keys, real photos or a person.

Last updated: 2026-10-27 (commit after `c591933`).
